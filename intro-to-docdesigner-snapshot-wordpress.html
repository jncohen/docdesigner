Context

The HFWG template is designed for students and research assistants who already know the basics of R Markdown but do not know TeX. They can write text, code, figures, and tables in one .Rmd file, then let the template handle the PDF design.

This matters because the Lab needs consistent output across working papers, research notes, Snapshots, and blogposts. Without a template, every student has to make dozens of small design decisions. With the template, those decisions live in one shared system.

Finding

The core workflow is simple: write once in RStudio, then knit into multiple publication formats. The PDF uses the HFWG LaTeX template. The WordPress companion uses conservative HTML that can be pasted into the CUNY Academic Commons editor without depending on special plugins.

The Snapshot format is built for short, visual-forward public communication. Its first page uses a compact header, a lead paragraph, and one featured visualization. That makes it different from a standard report, which uses a fuller title page and more traditional academic structure.

Implication

For students, the practical lesson is that TeX is part of the production system, not something they need to edit directly. Their job is to write clear R Markdown, provide accurate YAML metadata, make readable figures, and inspect the knitted output.

For the Lab, the benefit is standardization. A research assistant can produce a PDF, a WordPress paste file, an image asset folder, and a publishing checklist from the same source document.
